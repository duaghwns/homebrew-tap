# Homebrew Tap

Homebrew formulae and casks by duaghwns.

## Installation

```bash
brew tap duaghwns/tap
brew install claude-usage-bar
brew install --cask hancut
```

## Formulae

| Formula | Description |
|---------|-------------|
| `claude-usage-bar` | macOS menu bar app for real-time Claude API usage monitoring |
| `hancut` (cask) | 한컷 — 비슷한 장면에서 베스트 컷만 건지는 RAW/JPG 셀렉 앱 ([releases](https://github.com/duaghwns/hancut-releases)) |
