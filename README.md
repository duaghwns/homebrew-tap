# Homebrew Tap

Homebrew formulae for [ClaudeUsageBar](https://github.com/duaghwns/ClaudeUsageBar).

## Installation

```bash
brew tap duaghwns/tap
brew install claude-usage-bar
```

## Formulae

| Formula | Description |
|---------|-------------|
| `claude-usage-bar` | macOS menu bar app for real-time Claude API usage monitoring |
